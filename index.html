📝 本週深層總結覆盤

🌟 執行原則：持續比完美重要 ｜ 成果比時數重要 ｜ 健康優先 ｜ 平衡比堆積任務重要 ｜ 每週調整，不必每天滿分

🌟

五大核心執行原則

01

持續比完美重要

忙碌或疲憊時，只要完成最低標準即可（如：跑步改為散步恢復、AI 學習 10 分鐘）。不中斷習慣鏈條是長期勝出的唯一秘訣。

02

成果比時數重要

AI 學習不只看影片或刷文章，要留下筆記、可運行的程式碼範例或實作成果，建立真正可對外展示的競爭力。

03

健康優先

絕不為了完成清單或熬夜學習而犧牲 7 小時睡眠與跑步恢復。充沛體能是所有專業與心靈的大後盾。

04

平衡比堆積任務重要

不只追求職涯與體能，也要照顧信仰、鋼琴興趣、家人與人際關係，維持身心靈健全的平衡計分卡。

05

每週調整，不必每天滿分

檢視長期趨勢，以每週回顧為抓手，逐步且溫和地改善自己的生活節奏。

Google 表單 & 試算表同步設定

自動將每日日期與完成項目記錄至 Google Form / Sheets

3 步驟超速設定
  1. 建立一個 Google 表單（例如題目含：「日期」、「完成項目」、「今日學習與反思」、「整體評分」）。
  2. 點擊表單右上角「⋮」選擇「取得預先填入的連結」，隨便填入字樣後按「取得連結」並複製。
  3. 將連結貼在下方「自動解析輸入框」，系統會自動抓取表單網址與 entry 代號！
Google 試算表 Web App 設定

只要在你的 Google 試算表「擴充功能」>「Apps Script」貼上下方預備好的程式碼，發布為「網頁應用程式」，並將網址貼在下方，即可完美寫入 Google Sheet 每一列！

Apps Script 範例程式碼（點擊複製） 
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      data.date,          // 日期 (例如: 10/25日)
      data.items,         // 完成項目清單
      data.score,         // 整體評分
      data.ai_log,        // AI 學習成果
      data.top3,          // 今日三件要事
      data.gratitude,     // 感恩日記
      data.best_thing,    // 最好的一件事
      data.improve_thing, // 改善的一件事
      new Date()          // 提交時間戳記
    ]);
    return ContentService.createTextOutput(JSON.stringify({result: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({result: "error", error: err}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
